## 0.2.1 兼容处理

- 工具 object schema 显式声明 additionalProperties；从实际宿主定位 `defineTool`。
- 工作目录来自宿主 runtime context，不再向已移除的 `cwd` 模板变量求值。
- complete prompt 补丁保留新版宿主的 required contexts。
- 源模板中的 `toolFilter` 原 deny 列表未删。运行时迁移为 `redteam-leaf`：子代理委派插件禁用，原 deny 名称额外由 `tools.guard` 单调拒绝；无 guard 时加载失败。
- 自动审批曾拒绝直接删掉旧限制的方案；该方案未执行。最终实现采用保留并加强叶子限制的兼容迁移，实际预设注册成功。

## 安装与发布约定

- 推荐长期保留的独立源码目录，通过单个 desktop profile 的 `link:` + Junction 引用，不修改另一个 Web profile。
- profile 的 package/patch 在写入前备份。宿主转换使用离线暂存，保留完整原始 ASAR 与 SHA-256 还原点；应用必须完全退出才允许切换。
- 本机产物、用户配置、运行时副本、测试日志与原始归档不提交到公共仓库。
- 真实安装结果另在本机保存，不用“副本通过”冒充“用户安装已经完成”。
